# 剑网3 名片卡

读取角色在游戏中的名片形象图，生成对应的底卡与正面头像，叠加文字、门派徽记、门派诗与条码，输出名片卡图片。

![示例](docs/sample.jpg)


## 命令

命令前的斜杠可省略，`名片卡` 与 `/名片卡` 等效。

### 绑定

```
绑定 区服名
```

为当前会话绑定默认区服。绑定后，两条命令均可省略服务器参数。不带参数时返回当前绑定。

### 名片卡

```
名片卡 服务器 角色名
名片卡 服务器 角色名 序号
名片卡 角色名
名片卡 角色名 序号
```

| 参数 | 说明 |
|---|---|
| 服务器 | 区服名称。已绑定区服时可省略 |
| 角色名 | 角色名称 |
| 序号 | 可选。指定使用第几张名片形象图，从 1 起；省略时随机选取 |

示例：

```
绑定 飞龙在天
名片卡 小螺卜头
名片卡 小螺卜头 1
名片卡 飞龙在天 小螺卜头
```

执行后先返回等待提示，生成完成后返回图片。

### 名片特写

```
名片特写 服务器 角色名
名片特写 服务器 角色名 序号
名片特写 角色名
名片特写 角色名 序号
```

前两个参数与「名片卡」相同，用于确定使用哪张名片形象图；序号为名片序号，可选。已绑定区服时同样可省略服务器。

命令执行后返回提示词清单，回复序号即按该提示词生成图片：

```
名片特写
1. 双眼特写
2. 双眼特写（电影黑条）
3. 多视角海报

发送序号即可，15 秒后自动选 1
```

- 清单内容取自配置项「名片特写提示词」，顺序即为序号
- 仅接受发起命令者的回复
- 15 秒内未回复时使用第 1 条
- 回复非数字提示「输入异常，结束会话」；序号超出范围提示「无效序号，结束会话」
- 提示词列表为空时提示「未配置提示词」

生成结果不叠加文字、徽记与条码，直接输出提示词生成的图片。

三条默认提示词的输出示例：

**1. 双眼特写**

**2. 双眼特写（电影黑条）**

## 配置

| 配置项 | 说明 |
|---|---|
| JX3API 基础地址 | 默认 `https://www.jx3api.com` |
| JX3API 接口令牌 | 在 <https://www.jx3api.com> 购买。可填多条，按顺序轮询使用 |
| 国内 HTTP 代理地址 | 用于 JX3API 请求，留空为直连 |
| 校验 JX3API 的 TLS 证书 | 默认开启 |
| 生图接口地址 | OpenAI 兼容地址，形如 `https://host/v1`；末尾省略 `/v1` 时自动补全 |
| 生图接口密钥 | 可填多条，按顺序轮询使用 |
| 生图模型名 | 默认 `gpt-image-2.5`。`gpt-image-2` 与 `gpt-image-2.5` 使用同一套接口格式 |
| 同时生成上限 | 默认 3，取值范围 1~20。超出时拒绝新请求并提示 |
| 开始生图任务提示 | 默认「正在努力生成图片中，请耐心等待几分钟...」。选择提示词后、开始生成前返回 |
| 名片特写提示词 | 模板列表，每条含名称与提示词内容。默认三条：双眼特写、双眼特写（电影黑条）、多视角海报。可自行增删，列表顺序即为返回给用户的序号 |
| 启用白名单 | 默认关闭。开启后仅白名单内的用户或会话可使用命令 |
| 白名单 | 用户 ID 或统一消息来源列表 |

生图请求不使用 HTTP 代理，与 JX3API 的代理配置相互独立。

### 密钥轮询

「JX3API 接口令牌」与「生图接口密钥」均支持填写多条，按列表顺序轮询使用：

- 每次请求从当前游标位置起取一条，成功后游标前进到下一条，多用户之间共享轮询位置
- 当前密钥被拒绝、限流或额度不足时，自动改用下一条，无需人工切换
- 超时、地址或模型名错误等非凭据问题不会切换密钥，直接返回错误
- 全部密钥都失败时，返回最后一条的错误信息
- 只填一条时行为与单密钥一致

### 白名单

默认关闭，所有用户均可使用命令。

开启后，仅名单内命中的用户可以使用。名单项支持两种写法：

| 写法 | 示例 | 作用范围 |
|---|---|---|
| 用户 ID | `123456789` | 仅该用户 |
| 统一消息来源 | `aiocqhttp:GroupMessage:123456789` | 该会话内的所有用户 |

统一消息来源的格式为 `平台适配器ID:消息类型:会话ID`，其中消息类型为 `GroupMessage`、`FriendMessage` 或 `OtherMessage`。含冒号的项按统一消息来源处理，其余按用户 ID 处理，两种写法可混用。

- 不在名单内的用户发送命令时，返回提示且不消耗令牌
- 名单为空时，所有用户都会被拒绝
- 白名单在两条命令上均生效

### 提示词列表

「名片特写提示词」为模板列表，在配置页可折叠展开：

| 字段 | 说明 |
|---|---|
| 名称 | 显示在返回清单中的名称 |
| 提示词内容 | 实际提交给生图接口的文本 |
| 尺寸 | 提交给生图接口的尺寸，形如 `2048x880`。默认 `2048x880`（21:9 横幅） |

- 新增条目时自行填写名称，清单中即显示该名称
- 删除条目后序号自动重排，不留空号
- 名称留空时按「提示词N」显示
- 内容为空的条目会被跳过
- 提示词中可使用 `{school}`、`{scene}`、`{accent}` 三个占位符，分别替换为门派、门派场景描述、门派主色；不含占位符时按原文提交
- 尺寸原样提交给生图接口，不做本地校验；各家服务接受的尺寸集合不同，按实际服务填写

### 生图响应

生图接口的响应按以下顺序解析，任一形式均可正常取图：

1. `b64_json` 字段，含 `data:image/png;base64,` 前缀的形式
2. `b64`、`image_base64` 字段
3. `url`、`image_url` 字段，由插件下载该地址

请求中一并要求 `response_format=b64_json`；若服务仍返回图片地址，则自动下载。

## 处理流程

```
取角色信息：GET /role/detail     门派、体型、阵营、帮会
取名片记录：GET /card/records    含 showAvatar 图片地址
        │
        ├── 生成无字底卡（场景、人物、面板、齿孔边框）
        └── 生成正面头像
                ↑ 两者并发执行，各自失败时重试；任一失败则整体失败
        │
模板叠加：门派名与等级、服务器、昵称、体型、阵营、帮会、
          门派徽记、门派诗、剑网3标识、日期、条码
        │
     输出图片
```

底卡与头像由生图接口生成；文字、徽记、条码等由模板渲染，不经过生图接口。

「名片特写」在此基础上多一步选择提示词：

```
名片特写 服务器 角色名 [名片序号]
        │
返回提示词清单 → 等待回复（15 秒，超时用第 1 条）
        │
按选定提示词生成图片 → 直接输出
```

## 接口

角色信息通过 JX3API 获取，涉及以下请求：

| 用途 | 接口 | 携带令牌 |
|---|---|---|
| 名片记录 | `GET /card/records` | 是 |
| 角色详情 | `GET /role/detail` | 是 |
| 名片形象图 | `/card/records` 返回的 `showAvatar` 图片地址 | 否 |

前两个接口请求「JX3API 基础地址」，参数为 `server` 与 `name`；`/role/detail` 额外带 `history=0`。

- `/card/records` 返回该角色的全部名片记录，每条包含 `showAvatar` 图片地址。命令未指定序号时从这些记录中随机选取一条，指定序号时按序号取。
- `/role/detail` 返回角色详情，取其中的 `forceName`（门派）、`bodyName`（体型）、`campName`（阵营）、`tongName`（帮会）、`roleName`（昵称）。

## 令牌消耗

两个命令每执行一次，均消耗 **2 次** JX3API 接口令牌：

1. `GET /card/records`
2. `GET /role/detail`

名片形象图的下载不计入令牌消耗。生图使用生图接口密钥，与 JX3API 令牌无关。

「名片特写」在提示词选择完成后才发起上述请求，因此超时或输入异常时不会消耗令牌。
